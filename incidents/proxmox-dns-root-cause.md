# Proxmox host DNS root cause (tailscale accept-dns)

## What Happened
This is the root-cause fix for a pattern that had already broken three separate hosts independently over the course of a few weeks, a repo mirror sync, a game server build, and a tailnet join. Each time, a host ended up with DNS pointed at a tailnet nameserver instead of the local DNS server, and each time it was fixed reactively on that one host without asking why it kept happening.

## Investigation
- Checked the Proxmox host's own `/etc/resolv.conf`: pointed at Tailscale's MagicDNS resolver, explicitly flagged as machine-generated ("DO NOT EDIT THIS FILE BY HAND, CHANGES WILL BE OVERWRITTEN").
- `tailscale debug prefs | grep -i dns` confirmed Tailscale's `accept-dns` setting was on, and actively overwriting the host's resolver configuration with its own.

## Root Cause
Proxmox LXCs inherit their default DNS config from the host at creation time. With `accept-dns` on, the host itself was resolving through Tailscale, not the local DNS server, so every new LXC got that same wrong default from the start. This also plausibly explains the "broke after a host-level event" pattern, not just new LXC creation, a Tailscale restart or reconnect during a host upgrade can reassert this overwrite at any time.

## Fix
1. Checked Tailscale's own backup of the pre-takeover config before changing anything: it showed the router, predating the local DNS server's existence, not useful to restore as-is.
2. Decision: since the router itself already forwards DNS to the local server network-wide, and every other machine in the lab already uses that server directly, pointed the host straight at it rather than restoring the old router-only value.
3. Disabled `accept-dns`, confirmed the host is on static networking with no other service managing this file, so nothing else should contest the change going forward.
4. Set the resolver explicitly and confirmed it held.

This prevents the pattern for any new host created from here on. It doesn't retroactively fix any already-affected host, those get caught individually if they resurface.
